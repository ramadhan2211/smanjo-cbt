PETUNJUK CARA HOSTING WEBSITE INI KE GITHUB PAGES:
  1. Buat akun di GitHub.com dan buat Repository Baru bernama sman1wongsorejo (Atur Public).
  2. Simpan file website ini sebagai index.html.
  3. Upload file index.html tersebut ke dalam Repository GitHub yang baru dibuat.
  4. Buka menu Settings > Pages pada repository.
  5. Pada opsi Branch, pilih main / master, folder /(root), lalu klik Save.
  6. Tunggu 1-2 menit, landing page SMANJO akan aktif secara gratis di URL: https://username.github.io/sman1wongsorejo
